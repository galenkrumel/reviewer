# reviewer

Self-hostable GitHub code review agent. Requirements: `REQUIREMENTS.md`.

## Agent skills

### Issue tracker

Issues live in GitHub Issues on `galenkrumel/reviewer`, managed via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root, created lazily. See `docs/agents/domain.md`.
